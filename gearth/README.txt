ISORA - MANUAL G-EARTH PREPARATION (WINDOWS X64)

1. Close G-Earth and Isora.
2. Create Isora/command.txt from the descriptor here. Place Isora.cmd and
   the complete portable app inside Isora/extension/. Copy the entire Isora
   folder into G-Earth's Extensions folder. Keep its name: Isora. Use the active Extensions folder if your
   G-Earth uses a custom data directory.
3. Check the resulting files:
     Extensions/Isora/command.txt
     Extensions/Isora/extension/Isora.cmd
     Extensions/Isora/extension/Isora.exe
     Extensions/Isora/extension/resources/app.asar
4. Start G-Earth. It registers Isora in the background using its port,
   extension name and authentication cookie. Play opens the window. No Node.js
   installation is needed.

The window X hides Isora; its features keep running in the background.
Stopping it from G-Earth ends the process and enables Restart and Remove. Opening
extension/Isora.exe directly starts standalone mode: use Connect G-Earth and
Disconnect normally. The ordinary Windows installer and portable ZIP also
remain available for standalone use.

Do not select Isora.exe through G-Earth's single-file installer: Electron
requires the rest of its files. This package is added by copying the complete
folder manually. It does not modify G-Earth or install anything automatically.

To update: close both applications and replace only Extensions/Isora with the
folder prepared from the new portable build. To remove: close both and delete Extensions/Isora.

If you used the former in-app installer, remove that old Isora folder manually
before copying this package. Do not run two copies at the same time.

No G-Earth-specific archive is generated by npm run make.

After upgrading, restart G-Earth once to refresh the row button permissions.
